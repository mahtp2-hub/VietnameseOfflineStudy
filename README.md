# Vietnamese Offline Study

Android app for offline Vietnamese transcription and Vietnamese-Japanese dictionary lookup.

## Target device
LG VELVET L-52A (Android 12, Snapdragon 765G, RAM 6GB)

## Planned features
- Import MP3 files
- Offline Vietnamese speech recognition using Whisper
- Display transcription text
- Tap Vietnamese words to show Japanese meanings
- Offline SQLite dictionary

## Status
Project initialization. APK not built or tested yet.
